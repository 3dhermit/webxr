# Asset notices — anatomy models

## heart-male.glb / heart-male.opt.glb

- **Source:** HuBMAP / Human Reference Atlas (humanatlas.io), *3D Reference Object Library*
- **Object:** Reference organ — heart, male (v2.5 library, object version `v1.3`)
- **Retrieved:** 2026-11-04 from
  `https://cdn.humanatlas.io/digital-objects/ref-organ/heart-male/v1.3/assets/3d-vh-m-heart.glb`
  and `.../crosswalk.csv`
- **Landing page:** `https://purl.humanatlas.io/ref-organ/heart-male/v1.3`
- **Licence:** **CC BY 4.0** (attribution only; no share-alike, commercial use permitted)
- **Attribution line (shown in-app and in course materials):**
  > Anatomy model: HuBMAP Human Reference Atlas, "Reference organ — heart, male" (v1.3),
  > used under CC BY 4.0. Source: https://purl.humanatlas.io/ref-organ/heart-male/v1.3
- **Structure:** 14 meshed parts under 3 system groups. Per-part identity ships inside the
  file as `node.extras` → `{ ontologyid (UBERON:/FMA:), label, representation_of }`, which
  three.js exposes as `mesh.userData`.
- **Provenance note:** original file generated by the Babylon.js glTF exporter for
  Autodesk Maya 2023.2 (`heart-male.glb`, 4.07 MB, 164,119 triangles). `heart-male.opt.glb`
  is the same model after `gltf-transform optimize --compress meshopt --meshopt-level high
  --flatten false --join false --instance false --palette false` (656 KB, graph and per-part
  names preserved on purpose — `--join`/`--flatten` default to true and would merge the parts
  and destroy per-part identity). Loading the .opt file needs a Meshopt decoder.
- **Not for clinical use.** Reference geometry for teaching only; verify against an
  authoritative anatomical source before clinical or assessment use.

## heart-male-textured.opt.glb (modified)

- **Derived from** `heart-male.glb` above (HuBMAP Human Reference Atlas, CC BY 4.0).
- **Changes made:** UV-unwrapped and textured with PBR maps (base colour, normal,
  occlusion/roughness/metallic) in Adobe Substance 3D Painter 12.2.0 for this project.
  Geometry is unchanged. Source export: `assets-source/heart-male-textured.glb`.
- **Attribution line when this model is shown:**
  > Anatomy model: HuBMAP Human Reference Atlas, "Reference organ — heart, male" (v1.3),
  > used under CC BY 4.0, UV-unwrapped and textured for this lesson.
  > Source: https://purl.humanatlas.io/ref-organ/heart-male/v1.3
- **Pipeline:** `node tools/painter-glb-fix.mjs` (restores unique mesh names and per-part
  ontology ids that the Painter export drops), then `gltf-transform optimize` with
  `--compress meshopt --texture-compress webp --texture-size 1024` and the same
  graph-preserving flags as above.
